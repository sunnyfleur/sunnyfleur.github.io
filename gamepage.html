A curated map of games that influenced how I think about worlds, stories, systems, player feeling, and the lessons that come from friction.

This page is not a tier list. It is a set of editorial shelves: games I lived in, stories that stayed with me, loops I kept returning to, systems I learned from, milestones that shaped my taste, and flawed experiences that still taught useful design lessons.

Design takeaways

What these games trained me to notice

World texture

Small travel beats, local stakes, and environmental memory make a place feel authored.

Readable goals

Strong loops keep the next useful action clear without flattening discovery.

System tension

Good progression asks the player to trade comfort, risk, economy, and timing.

Style as function

UI, music, routine, and pacing work best when they reinforce the same fantasy.

Player trust

Friction is useful when it teaches; it becomes noise when feedback feels unfair.
